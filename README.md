# AI Coding Dictionary

这是 [AI Coding Dictionary](https://www.aicodingdictionary.com/) 的本地学习复刻，用来对照原站的知识图谱和词条面板。它不是官方站点，也不由原作者维护。

## 源站

- 网站：https://www.aicodingdictionary.com/
- 带词条的地址形如：https://www.aicodingdictionary.com/?term=context-window

## 相关官方仓库与页面

- 词条 Markdown 仓库：[mattpocock/dictionary-of-ai-coding](https://github.com/mattpocock/dictionary-of-ai-coding)。本仓库里的英文词条正文、分组和链接来自这里。
- AI Hero 上的词典入口：https://www.aihero.dev/s/dictionary
- AI Hero 上的单条词条：`https://www.aihero.dev/ai-coding-dictionary/<slug>` ，例如 https://www.aihero.dev/ai-coding-dictionary/context-window
- 作者：Matt Pocock

## 许可

[mattpocock/dictionary-of-ai-coding](https://github.com/mattpocock/dictionary-of-ai-coding) 没有 LICENSE。这里保留其词条正文，只作学习对照，不把这些正文当作可以再授权的内容。图谱交互和面板是这次实验自己实现的。
